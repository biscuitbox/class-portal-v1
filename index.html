      🔗 Firebase 연결하기

      ⚪ 설정 전 — 이 브라우저에만 저장됩니다 로그인하지 않음
      1. 프로젝트 만들기 console.firebase.google.com 에서 프로젝트를 만들고, Firestore Database를 프로덕션 모드로 켭니다. 이어서 Authentication → 로그인 방법 → Google을 사용 설정하세요. 모두 무료 요금제(Spark)로 충분합니다.
      2. 설정값 붙여넣기 프로젝트 설정 → 내 앱 → 웹 앱(</>)을 추가하면 firebaseConfig가 나옵니다. 이 HTML 파일을 메모장으로 열어 맨 아래 ▼▼▼ 여기에 붙여넣으세요 ▼▼▼ 자리의 "여기에_붙여넣기"를 실제 값으로 바꾸고 저장하세요.
      3. 보안 규칙 넣기 Firestore Database → 규칙 탭에 아래 내용을 붙여넣고 게시합니다. 아래 칸에 선생님 구글 이메일을 적으면 규칙이 자동으로 바뀝니다.
      보안 규칙 — 안내판은 선생님만, 시험 범위는 학생도 쓰기 복사했습니다 
      

          
      
            시험 범위 탭을 쓰려면 규칙을 다시 붙여넣어야 합니다.
            예전 규칙에는 classExam 부분이 없어서, 학생이 시험 범위를 적어도 저장되지 않습니다.
            위 규칙을 통째로 복사해 Firestore 규칙 탭에 붙여넣고 게시해 주세요.
            학생은 과목 칸을 만들고 고칠 수 있고, 지우는 것은 선생님만 할 수 있습니다.
          
      
          
      
            firebaseConfig는 코드에 그대로 두어도 됩니다.
            이 값은 "우리 프로젝트 주소"일 뿐이라 공개되어도 괜찮게 설계되어 있습니다.
            실제로 누가 무엇을 읽고 쓸 수 있는지는 위의 보안 규칙이 정합니다.
            그래서 규칙을 반드시 넣어야 합니다.
          
      
          
      
            절대 코드에 넣으면 안 되는 것은 서비스 계정 키(service account key)입니다.
            private_key가 들어 있는 JSON 파일이 그것으로, 이 파일이 있으면 규칙을 무시하고 무엇이든 할 수 있습니다.
            웹 페이지·깃허브·메신저 어디에도 올리지 마세요. 이 안내판은 서비스 계정 키를 쓰지 않습니다.

      🔒 학생 화면 잠금
      
          
      
            🔓 잠금 패턴 없음 — 누구나 교사 화면으로 돌아올 수 있습니다
            
            
          
      
          
      
            패턴을 정해 두면, 학생 화면에서 교사용으로 돌아가기를 눌렀을 때 패턴을 그려야 넘어갑니다.
            교실 TV나 교사 PC를 학생이 만질 때 대비용입니다. 다섯 번 틀리면 30초 동안 다시 시도할 수 없습니다.
          
      
          
      
            패턴은 이 브라우저에만 저장되며 다른 기기·서버로 가지 않습니다.
            그래서 학생용 주소(?mode=student)로 연 기기에는 애초에 돌아가기 버튼이 나오지 않습니다.
            패턴을 잊으면 이 브라우저의 방문 기록·사이트 데이터를 지우면 초기화됩니다.
          
      
        
      

        
      
          
      🚀 학생에게 보여 주기
      
          
      
            구글 로그인과 학생 공유는 웹 주소(https://)로 열었을 때만 동작합니다.
            파일을 두 번 눌러 여는 방식(file://)에서는 이 브라우저에만 저장됩니다.
            깃허브 페이지(GitHub Pages)나 학교 홈페이지에 이 HTML 파일 하나만 올리면 됩니다.
          
      
          
      
            학생용 주소는 올린 주소 끝에 ?mode=student를 붙인 것입니다.
            학생은 로그인 없이 보기만 할 수 있고, 편집 버튼과 모둠·발표 뽑기는 보이지 않습니다.
            지금 이 페이지의 학생용 주소: 
          
      
          
      
            인터넷이 막히거나 설정을 하지 않았을 때도 안내판은 그대로 쓸 수 있습니다.
            그때는 예전처럼 이 컴퓨터의 이 브라우저에만 저장되고, 연결이 되면 다시 모두에게 공유됩니다.
          
      
        
      

      
      
    
      

  
      

  
      
    
      
      입력한 내용은 이 컴퓨터의 이 브라우저에만 저장됩니다. (다른 기기와 공유되지 않으며, 방문 기록·캐시를 지우면 함께 사라집니다.)
      
      개인정보 보호를 위해 학생 이름 대신 번호를 사용해 주세요. (예: "3번 준비물 확인", "12번 보건실 방문")
